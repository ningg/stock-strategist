# 财报术语表附录规则

报告**必须**在证据来源之后、免责声明之前包含 `## 附录：财报典型术语表`。

## 编写原则

1. **只收录本报告正文中实际使用的术语**——不要堆砌通用金融词典
2. **结合该公司最新财报填数字示例**（如「Q1 经调整净亏损 49.7 亿元」）
3. 每条三列：**术语 | 全称（英文）| 含义（简要）**
4. 同一术语全文统一写法（如始终用「经调整净利润」而非混用 Adj NP）

## 七类分组

按公司类型选取相关类别，空类别可省略。

### 一、核心财务指标

| 术语 | 何时收录 |
|------|---------|
| Revenue / 收入 | _always_ |
| Gross Profit / 毛利 | 讨论利润率时 |
| Operating Profit / 经营利润 | _always_ |
| Net Profit / 净利润 | _always_ |
| Adjusted Net Profit / 经调整净利润 | 港股/中概/科技股 |
| Adjusted EBITDA | 披露 Non-IFRS 时 |
| Non-IFRS | 港股 |
| SBC / 股权激励费用 | SBC 占收入 >1% 或讨论稀释 |
| OCF / 经营现金流 | 模块 C |
| CapEx / 资本支出 | 模块 C |
| YoY / QoQ / Beat·Miss | 出现即收录 |
| GAAP vs IFRS | 美股 |

### 二、业务分部与收入科目

收录公司财报中的**分部名**和**收入科目**变更，例如：

- Core Local Commerce / 核心本地商业
- Segment operating profit / 分部经营利润
- Delivery services / Merchant services / Product sales
- Incentives deducted from revenues / 从收入中扣除的激励
- Unallocated items / 未分配项目

### 三、运营与竞争指标

| 术语 | 典型场景 |
|------|---------|
| UE / Unit Economics | 平台、外卖、订阅 |
| GMV / GTV | 电商、本地生活 |
| AOV | 外卖、零售 |
| OPM / Take Rate | 讨论变现 |
| Daily Orders / MAU / DAU | 用户/订单型 |
| ARR / NDR | SaaS |
| Rule of 40 | 高增长 SaaS |

### 四、产品、品牌与战略名词

公司特有产品、子品牌、战略口号（如 Keeta、LongCat、Retail + Technology）。

### 五、估值、研究与投资术语

本报告使用的：TP、Consensus、P/E、P/S、EV/EBITDA、DCF、WACC、Net Cash、Variant View、Kill Condition、Action Price、PGMV 等。

### 六、监管、治理与宏观

SAMR、WVR、Earnings Call、Guidance、反内卷、EBITA；美股用 SEC、10-K、Form 4 等。

### 七、时间缩写

Q1–Q4、FYxxxx、FYxxxxE、H1/H2、TTM、E（Estimate）。

## 质量检查

- [ ] 每个 Key Force 或 KPI 里的缩写都在术语表中有解释
- [ ] 含义行 ≤ 2 句话，避免复制百科
- [ ] 数字示例与报告正文一致
- [ ] 未出现「参见上文」式空解释
