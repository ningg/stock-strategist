# 3690.HK: 补贴战账单落地后，美团进入「修复交易」窗口

> 本报告数据均来自外部公开来源（HKEX公告、美团IR、Yahoo Finance、卖方研报、财经媒体），未引用项目内任何历史分析文档。

## 执行摘要

**推荐动作：买入 | 信心水平：中**

2026年6月1日，美团发布2026Q1财报，为持续一整年的外卖补贴大战（2025Q2–2026Q1）画上句号。营收910亿元（+5.6% YoY），调整后净亏损49.7亿元——较Q4的151亿元收窄67%，显著优于FactSet共识预期的85亿元亏损。CEO王兴在电话会上表示：「仅依靠补贴推动的订单增长不可持续」；若竞争保持理性，Q2外卖UE（单均经济模型）将较Q1显著改善。

当前股价约79.95港元（Yahoo Finance，2026-06-05），市值4940亿港元，较52周高点149.8港元回撤47%。净现金约1800亿元人民币（Yahoo引最近一季总现金1804亿），占市值约34%。9家大行Q1财报后目标价区间85–125港元，均值约112港元；招银国际DCF目标价138港元，招商证券PGMV目标价135.6港元。

**独立估值合理区间95–118港元；扣除15–18%安全边际后，买入价72–76港元、加仓价65–70港元、减仓价125港元以上。**

**Kill Condition**：连续2季核心本地商业经营利润率低于-8%；餐饮外卖日均单量跌破5500万；或Q3纯餐饮外卖UE再度转负。

**TL;DR**
- **买入（中）**：Q1减亏超预期 + UE修复可见 + 估值处于历史低位
- **Key Force**：补贴战退潮 → 盈利修复（销售费用率Q4 34.4%→Q1 25.2%）
- **Key Force**：竞争格局从垄断变为寡头——份额永久丢失，但GMV与高AOV订单仍领先
- **Key Force**：新业务（小象+Keeta）+21.3%增长、减亏至-7.8%
- **Variant View**：市场按「永久受损」定价，低估了减亏斜率

## Key Forces

### 1. 补贴战退潮 → UE修复（决定性力量）

**时间线（外部来源综合）：**
- 2025年2月：京东宣布入局外卖；5月淘宝闪购上线，补贴战升级
- 2025Q3：三家餐饮外卖日均订单总和一度超2亿单，三家单季净利润同比降幅均超50%（新浪财经/钛媒体）
- 2025全年：美团、阿里、京东在外卖上至少烧掉1500亿元（定焦One/新浪财经，2026-06-04）
- 2026年3月：市场监管总局为外卖大战「划句号」；各平台收紧补贴（东方财富网）
- 2026Q1：补贴明显退潮，美团减亏超预期

**Q1财务拐点（HKEX公告，2026-06-01）：**

| 指标 | Q1 2026 | Q4 2025 | QoQ |
|------|---------|---------|-----|
| 经营亏损 | 65亿 | 161亿 | -60% |
| 核心本地商业经营亏损 | 20亿 | 100亿 | -80% |
| 调整后净亏损 | 50亿 | 151亿 | -67% |
| 销售营销费用率 | 25.2% | 34.4% | -9.2ppt |
| 核心本地商业经营利润率 | -3.2% | -15.5% | +12.3ppt |

**王兴原话（网易科技引财报电话会，2026-06-02）：**
> "仅依靠补贴推动的订单增长是不可持续的。如果行业竞争能够保持当前理性状态，叠加二季度旺季效应，预期第二季度外卖UE将较第一季度实现显著改善。"

花旗（2026-06-02）预计Q2外卖UE恢复盈亏平衡，核心本地商业重返盈利——较此前预测提前。

### 2. 竞争格局永久改变——从「垄断溢价」到「寡头博弈」

**订单格局（定焦One引美团内部人士，2026Q1）：**
- 美团餐饮外卖日均约6500万单
- 淘宝闪购约5000万单
- 京东外卖约900万单
- 比例与2025Q4基本持平，整体单量从峰值回落

**美团内部策略（同上）：**
> "在保证份额领先的前提下缩减补贴，可以接受竞争对手的日均单量不超过自己的80%。"

**份额变化：**
- Compounder Fund引2024年份额约65%，2025–2026补贴战后订单份额 reportedly 45–52%（Moschovakis Capital）；管理层强调AOV>30元订单份额仍>70%（招银国际）
- China Biz Insider（2026）：高价值订单（>30元）份额从7:3被侵蚀至接近6:4

**三方差异化逻辑（网易科技）：**
- **美团**：外卖UE必须独立转正，生死线
- **阿里**：淘闪是电商生态入口，HSBC测算12个月即时零售亏损870亿，中长期仅要求微利
- **京东**：从全面进攻转向收缩，Q1新业务亏损103.5亿但环比从148亿收窄

**投资含义**：美团不会再回到25–30x PE的垄断溢价时代，但6500万单/日的规模+履约效率仍构成实质壁垒。当前1.06x EV/Revenue（Yahoo Finance）已price-in格局变化。

### 3. 新业务减亏 + 「Retail + Technology」转型

Q1新业务270亿元（+21.3% YoY），经营亏损21亿元，亏损率-7.8%（Q4为-17.1%）。

- **小象超市**：55城，商品销售驱动（Q1起单独披露商品销售收入）
- **Keeta**：香港+沙特效率提升，巴西扩张中
- **AI**：研发70亿（+22% YoY，占收入7.7%）；LongCat-2.0万亿参数模型；小团AI助手「五一」服务过亿人次；智能掌柜70万+商户
- **无人机**：90万+商业订单，全球第二（美团官方新闻稿）

2026Q1起调整收入披露口径：单独列示商品销售收入，合并佣金+广告为「商户服务收入」——战略重心从纯平台抽佣转向零售+科技。

## Variant View

**市场共识：** 补贴战证明美团护城河远不如想象——份额永久丢失、远期OPM从20%+下修至5–8%，估值框架从「平台垄断」切换为「寡头苦战」，即使UE修复也不值得旧估值。

**我们的观点：** 共识对格局变化的判断基本正确，但对**修复速度**定价不足。Q1核心本地商业亏损从100亿→20亿（-80% QoQ）的减亏斜率，以及王兴确认Q2 UE显著改善，意味着2026E可能是盈亏平衡而非继续大幅亏损（招银预测2026E Adj NP -25亿，招商预测-12.6亿）。当前79.95港元接近Simply Wall St bear case（78.22），却在交易一个「尚未修复」的叙事。

**为什么可能错：** 若Q2盈利兑现（8月财报验证），市场需重新定价2027年200亿+利润——对应20x PE约110–120港元，距现价有40%+空间。

## 附录：财报典型术语表

以下术语均在本报告或美团 HKEX 业绩公告（2026Q1 / FY2025）中出现，按类别整理，便于对照阅读。

### 一、核心财务指标

| 术语 | 全称 | 含义（简要） |
|------|------|-------------|
| **Revenue / 收入** | — | 报告期内平台确认的总营业收入，美团 2026Q1 为 910 亿元。 |
| **Gross Profit / 毛利** | — | 收入减去营业成本（Cost of Revenues）后的余额；反映定价与直接成本控制能力。 |
| **Operating Profit (Loss) / 经营利润（亏损）** | — | 毛利减去销售营销、研发、管理费等运营费用后的结果；美团 Q1 经营亏损 65 亿元。 |
| **Net Profit (Loss) / 净利润（净亏损）** | — | 经营结果经财务费用、投资收益、所得税等调整后的最终盈亏；Q1 净亏损 68 亿元。 |
| **Adjusted Net Profit / 经调整净利润** | Non-IFRS Adjusted Net Profit | 在 GAAP/IFRS 净利润基础上，加回 SBC、并购摊销、投资公允价值波动等非经常性项目；Q1 调整后净亏损 49.7 亿元，是卖方和投资者最常用的盈利指标。 |
| **Adjusted EBITDA** | Earnings Before Interest, Taxes, Depreciation and Amortization（经调整） | 经调整息税折旧摊销前利润，近似反映主营业务的现金创造能力，剔除折旧摊销和非经营项；Q1 为 -30 亿元。 |
| **Non-IFRS / 非 IFRS 指标** | Non-IFRS Accounting Standards Measures | 香港上市公司常用的补充披露口径，便于跨期、跨公司比较，但不同于法定财报数字。 |
| **SBC / 股权激励费用** | Share-Based Compensation | 以股票/期权支付员工薪酬产生的非现金费用；Q1 约 13.8 亿元，占收入 1.5%。 |
| **OCF / 经营现金流** | Operating Cash Flow | 经营活动产生的现金净流入/outflow；Q1 为 -70 亿元，亏损期常见，需结合利润质量一起看。 |
| **CapEx / 资本支出** | Capital Expenditure | 购建固定资产、系统等长期资产的现金流出；美团用于配送网络、AI、零售供应链等。 |
| **YoY / QoQ** | Year-over-Year / Quarter-over-Quarter | 同比 / 环比，衡量增速或利润率变化方向。 |
| **Beat / Miss** | Beat/Miss vs Consensus | 实际业绩优于/劣于华尔街或卖方一致预期；本季调整后净亏损 beat 约 42%。 |

|------|------|-------------|

| **Unallocated Items / 未分配项目** | — | 总部层面的 SBC、并购摊销、投资公允价值变动、监管罚款等，不归属具体分部；Q1 未分配经营亏损约 23 亿元。 |

### 三、运营与竞争指标

| 术语 | 全称 | 含义（简要） |
|------|------|-------------|
| **UE / 单均经济模型** | Unit Economics | 每完成一单外卖/即时配送所赚或所亏的净利润；王兴称 2026 年 4–5 月纯餐饮外卖 UE 已转正，是修复交易的核心跟踪指标。 |
| **GMV / 商品交易总额** | Gross Merchandise Volume | 平台上成交的商品/服务总金额（含未抽佣部分）；份额讨论常用 GMV 口径，高于「收入」口径。 |
| **GTV / 总交易额** | Gross Transaction Value | 与 GMV 类似，多用于到店、酒旅等场景的总流水。 |
| **AOV / 平均客单价** | Average Order Value | 每单平均金额；美团在 AOV>30 元的「高价值外卖」订单中仍占 >70% 份额（卖方估算）。 |

| **Take Rate / 变现率** | — | 平台收入占 GMV 的比例，反映抽佣+广告+配送等综合变现能力；竞争补贴期 take rate 被压低。 |
| **Daily Orders / 日均单量** | — | 餐饮外卖日均订单数；2026Q1 美团约 6500 万单/日，是份额与规模的核心运营指标。 |
| **On-demand Delivery / 即时配送** | — | 外卖+闪购等「下单后短时间送达」的业务统称，美团核心能力所在。 |
| **Instashopping / 闪购** | Meituan Instashopping | 非餐饮即时零售（超市、鲜花、药品等）；日单量 >1800 万，00 后用户为增量来源。 |

### 五、估值、研究与投资术语

| 术语 | 全称 | 含义（简要） |

| **Consensus / 一致预期** | — | 多家分析师预测的平均值；FactSet 共识 Q1 调整后净亏损约 85 亿元。 |
| **P/E / 市盈率** | Price-to-Earnings Ratio | 股价 ÷ 每股收益；亏损期 P/E 失效，常看 forward P/E（2027E 盈利恢复后适用）。 |

| **WACC** | Weighted Average Cost of Capital | 加权平均资本成本，DCF 折现率；招银采用 11%。 |
| **Net Cash / 净现金** | — | 现金及等价物 + 短期理财 - 有息负债；美团约 1800 亿元人民币，是重要的下行保护垫。 |
| **Variant View / 变异视角** | — | 与市场共识不同的核心投资论点；本报告认为市场低估了减亏速度。 |
| **Kill Condition / 退出条件** | — | 预设的硬性卖出触发条件，如份额持续流失或 UE 再度恶化。 |
| **Action Price / 行动价** | — | 基于独立估值（非当前股价）推导的买入/加仓/减仓价格区间。 |
