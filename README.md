# 股票价值投资分析系统

> 股票市场，自己的谋士，基于一定原则、收集信息、给出分析和决策建议，最终决策，还是要自己做。

## 📋 项目简介

这是一个基于价值投资理念的股票分析系统，专注于从以下三个核心维度进行深度分析：

1. **未来现金流的折现** - 评估企业的盈利能力和现金流质量
2. **商业模式** - 分析企业的商业逻辑和竞争优势
3. **企业文化** - 评估企业的价值观和执行能力

## 🎯 核心原则

### 数据要求
- ✅ 数据范围：只能以 2025年之后的信息为准
- ✅ 数据来源：财报、新闻、行业报告、公司公告、分析师报告等
- ✅ 数据准确性：确保数据的准确性，不能有误差
- ✅ 数据完整性：确保数据的完整性，不能有遗漏
- ✅ 数据及时性：确保数据的及时性，不能有滞后

### 分析框架

**关注事项：**
- **中期**：短期新闻、价值、价格
- **短期**：情绪、周期（同行业中其他标的）
- **财报**：最近连续 4 个季度的财报(2025年)，获取最新的财报信息

**基本规则：**
- 没有倒闭风险：现金流、资产、负债
- 商业模式：是否满足旺盛需求、市场占有率、市场是否还有增长空间、自身增长潜力
- 企业文化：是否用最少的钱，获取最多的增量
- 核心业务：专注 or 多样化扩张？

## 🔍 分析方法

每份分析报告包含以下内容：

1. **执行摘要** - 快速了解核心结论和投资建议
2. **未来现金流折现分析** - 详细的财务分析和现金流评估
3. **商业模式分析** - 商业模式评估和竞争优势分析
4. **企业文化分析** - 企业文化评估和执行能力分析
5. **综合评估与投资建议** - 综合评分和具体投资建议
6. **参考来源** - 所有数据的来源标注

## 📈 使用说明

### 本地运行（支持热重载）

1. 安装 docsify-cli（如果还没有安装）：
```bash
npm i docsify-cli -g
```

2. 在项目根目录运行：

```bash
# 方式1：直接使用 docsify 命令
docsify serve .

# 方式2：使用 npm 脚本（推荐）
npm run serve

# 方式3
npm run dev
```

3. 自动打开浏览器或访问：http://localhost:3000

**🔥 热重载功能**：
- `docsify serve` 默认支持**自动监听文件变化**
- 编辑任何 `.md` 文件并保存后，浏览器会**自动刷新**
- 无需手动刷新页面，无需重启服务器

### 部署到 GitHub Pages

1. 在 GitHub 仓库设置中启用 GitHub Pages
2. 选择 `main` 分支的 `/ (root)` 目录
3. 访问 `https://yourusername.github.io/stock-strategist`
